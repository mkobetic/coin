# coin2html JS/TS Subproject — Agent Guidelines

This directory (`cmd/coin2html/js/`) is a standalone TypeScript and D3.js single-page application that powers the interactive HTML ledger viewer generated by `coin2html`.

It is designed to be developed, tested, and linted independently of the parent Go project, communicating with the Go host exclusively via embedded `<script type="application/json">` data tags and outputting bundled HTML fragments to `dist/`.

## Architecture & Packaging Constraints

- **Single-File Serverless Goal**: Everything (HTML structure, CSS styles, TypeScript code, and assets) is bundled and inlined by Webpack (`html-bundler-webpack-plugin` in `webpack.config.js`) into two fragment files:
  - `dist/head.html` (generated from `head.html` + inlined `styles.css`)
  - `dist/body.html` (generated from `body.html` + inlined TypeScript bundle from `src/ui.ts`)
  - The viewer must run directly from a local `file://` URL or static host with **zero server infrastructure or external runtime requests**.
- **Selective D3 Imports**:
  - D3.js is used for both DOM/table manipulation and charts.
  - Import only the specific D3 submodules needed (e.g., `d3-selection`, `d3-scale`, `d3-time`, `d3-hierarchy`, `d3-array`, `d3-shape`, `d3-axis`) rather than importing the entire `d3` umbrella package, to keep the generated HTML file size manageable.
  - `jest.config.js` maps `^d3-(.*)$` to `<rootDir>/node_modules/d3-$1/dist/d3-$1.min.js` for CommonJS compatibility in Jest.

## Project Layout

- `head.html`, `body.html`, `styles.css`: Static HTML skeleton and styles.
- `src/commodity.ts`: `Commodity`, `Amount` (float-based for UI visualization), `Price`, and weekly time-scale price `Conversion` functions (`newConversion`, `composeConversions`).
- `src/account.ts`: `Account`, `Transaction`, `Posting` models, tree traversal (`allChildren`, `withAllChildPostings`), and JSON loaders.
- `src/utils.ts`: Date helpers, `groupBy`, `PostingGroup`, `AccountPostingGroups`, `topN`, and account name shortening.
- `src/ui.ts`: Entrypoint (`initializeUI`) that reads `#importedCommodities`, `#importedPrices`, `#importedAccounts`, and `#importedTransactions` from the DOM and wires top-level controls.
- `src/views.ts`: Global UI `State`, `Aggregation` intervals (`None`, `Weekly`, `Monthly`, `Quarterly`, `Yearly`), `AggregationStyle` (`Flows` vs. `Balances`), view registry (`Views`), and view control bar rendering.
- `src/viewsBalances.ts`, `src/viewsBalancesChart.ts`, `src/viewsRegister.ts`, `src/viewsAggregatedRegisterChart.ts`: Individual tabular and chart view implementations.
- `spec/*.spec.ts`: Jest unit test suites (`commodity.spec.ts`, `utils.spec.ts`, `setup.ts`).

## JSON Data Contract

The viewer reads four `<script type="application/json">` elements injected into the HTML page before `body.html`:

1. `#importedCommodities`: Map of commodity ID to `{ id, name, decimals, location? }`.
2. `#importedPrices`: Array of `{ commodity, currency, time, value, location? }`.
3. `#importedAccounts`: Map of full account name to `{ fullName, name, commodity, parent?, closed?, location? }` (parents listed before children).
4. `#importedTransactions`: Array of `{ posted, description, code?, notes?, tags?, location?, postings: [{ account, quantity, balance, balance_asserted?, notes?, tags? }] }`.

See [`README.md`](README.md) for full JSON examples. Do not change this schema without updating `cmd/coin2html/main.go` in the parent Go project.

## Development & Verification Commands

Run these commands either with `npm --prefix cmd/coin2html/js <cmd>` from the repo root or directly inside `cmd/coin2html/js/`:

- **Run unit tests (Jest)**:
  ```sh
  npm --prefix cmd/coin2html/js test
  ```
- **Check formatting and linting (Prettier + ESLint)**:
  ```sh
  npm --prefix cmd/coin2html/js run lint
  ```
- **Auto-fix formatting and lint issues**:
  ```sh
  npm --prefix cmd/coin2html/js run autolint
  ```
- **Build `dist/head.html` and `dist/body.html` (Webpack)**:
  ```sh
  npm --prefix cmd/coin2html/js run build
  ```
- **Install dependencies**:
  ```sh
  npm --prefix cmd/coin2html/js install
  ```

> **Note**: During pure TypeScript/UI iteration, you only need `test`, `lint`, and `build`. When ready to update the Go `coin2html` binary and sample viewer (`examples/yearly/viewer/index.html`), run `make coin2html examples` from the repository root.
